# UthaLe frontend

React + Vite + TypeScript + Tailwind v4 dashboard. See [../README.md](../README.md) for setup.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to http://127.0.0.1:8000
npm run build
npm run lint
```

Set `VITE_BACKEND_URL` to proxy to a different backend.
